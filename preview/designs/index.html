Ten directions for the interface

The same screen — Winter Orb, its cluster combinations, the crafting card — drawn ten different ways. Not ten colour schemes: a sidebar shell, a printed page, a table with an inspector, a magazine, a banner, a dashboard, a poster, a command palette, a ledger and an art wall. Nothing here is wired to the app. Pick a number, and I build that one for real.

The frames are alive: hover anything that looks like a control — buttons, rows, tiles, tabs — and it lifts and glows. Click a skill to change the build, a combination to change the crafting target, and in the first frame the size pills narrow the list. 1:1 opens a frame at full size.
